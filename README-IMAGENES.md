# Guía de Imágenes & Recursos Visuales - ATELIERLDIC AUDIO

Esta guía explica cómo funciona el sistema de imágenes del catálogo y cómo puedes agregar o sustituir las fotos de los 20 modelos de audífonos.

---

## 1. ¿Cómo funciona el sistema visual actual?
El catálogo cuenta con una **arquitectura de fallback inteligente**:
- Cada tarjeta busca su archivo correspondiente en la carpeta `images/` (ej. `images/huawei-freebuds-pro-5.png`).
- Si la imagen aún no está presente en la carpeta, el sistema activa de forma automática una **ilustración vectorial SVG de alta definición** con estética de cuero italiano, costuras artesanales y acabados metálicos en tonos café y latón.
- Esto significa que la página web es **100% funcional y visualmente atractiva desde el primer segundo**.

## 3. Especificaciones técnicas ideales de imagen
- **Formato:** PNG con fondo transparente (ideal) o WebP.
- **Resolución sugerida:** 800 x 800 px o 1000 x 1000 px (proporción 1:1 cuadrada).
- **Enfoque visual:** Fotografía de estudio en ángulo de tres cuartos (3/4 view) o frontal elevado.

---

## 4. Prompts sugeridos para generar imágenes con IA
Si deseas generar las imágenes mediante Midjourney, DALL-E 3, Imagen 3 o Stable Diffusion, utiliza una estructura como esta para mantener la coherencia de lujo:

```text
Studio product photography of [Nombre del Audífono], premium high-end audio gear, dark Italian leather texture background, warm directional rim lighting, subtle bronze and coffee reflections, clean transparent PNG cut out, 8k resolution, photorealistic, cinematic depth of field, luxury commercial aesthetics --ar 1:1
```

**Ejemplo específico para el Buque Insignia (Huawei FreeBuds Pro 5):**
```text
Studio product photography of futuristic luxury true wireless earbuds Huawei FreeBuds Pro 5, metallic ceramic finish, sitting elegantly on aged dark brown leather surface, warm ambient studio lighting, soft golden highlights, photorealistic, 8k --ar 1:1
```
